# Тестовое задание: автотесты pytest для СУБД

## Структура
test_mysql/

├── con_db_oracle.py             # основной вариант подключения, т.к. оракл указан как основнай СУБД

├── test_oracle.py               # тесты к оракл

├── docker-compose.yml           # _сервисы mysql и postgres_

├── con_db_mysql_only.py         # _подключение (вариант 2)_

├── test_simple_mysql_only.py    # _тесты (вариант 2)_

├── con_db.py                    # _подключения и словарь DATABASES (вариант 3)_

├── test_simple.py               # _параметризованные тесты (вариант 3)_

├── requirements.txt

└── README.md

## Вариант 1: Oracle

Основной файл с функцией для соединения с БД и файл с четырьмя тестами: 
проверяется подключение к БД, select sysdate from dual для получения времени, 
падение с неправильным паролем и получение ошибки

## Вариант 2: MySQL

Файл с функцией для соединения с БД и файл с четырьмя тестами: 
проверяется подключение к БД, SELECT.NOW(), 
падение с неправильным паролем и получение ошибки

## Вариант 3: MySQL + PostgreSQL

То же, но с параметризацией, чтобы попробовать тесты для 
двух разных СУБД. Можно добавлять и другие СУБД в DATABASES
