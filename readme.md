# Тестовое задание: автотесты pytest для СУБД

## Структура
test_mysql/

├── docker-compose.yml           # _сервисы mysql и postgres_

├── con_db_mysql_only.py         # _подключение (вариант 1)_

├── test_simple_mysql_only.py    # _тесты (вариант 1)_

├── con_db.py                    # _подключения и словарь DATABASES (вариант 2)_

├── test_simple.py               # _параметризованные тесты (вариант 2)_

├── requirements.txt

└── README.md

## Вариант 1: MySQL

Файл с функцией для соединения с БД и файл с четырьмя тестами: 
проверяется подключение к БД, SELECT.NOW(), 
падение с неправильным паролем и получение ошибки

## Вариант 2: MySQL + PostgreSQL

То же, но с параметризацией, чтобы попробовать тесты для 
двух разных СУБД. Можно добавлять и другие СУБД в DATABASES
