# Тестовое задание: автотесты pytest для СУБД

Я решила не ограничиваться своей основной СУБД
и сделать несколько, чтобы посмотреть, в чем будет разница

## Структура
test_mysql/

├── con_db.py                    # _подключения и словарь DATABASES_

├── test_simple.py               # _параметризованные тесты_

├── reports.html                 # _результаты тестов_

├── docker-compose.yml

├── requirements.txt

└── README.md

## Состав тестов:

1. Фикстура на подключение к БД
2. Выполнение запроса получения времени
3. Запланированное падение с неправильным паролем
4. Обработка ошибки при неправильном пароле
